# **App Name**: Project Forge

## Core Features:

- Project Initialization: Generate a new Next.js project with TypeScript support, pre-configured TailwindCSS, and necessary project structure.
- Tailwind Setup: Install and configure TailwindCSS v3.14 without PostCSS preprocessing. Ensure proper configuration in `tailwind.config.js`.
- Supabase Installation: Install Supabase client library for future database integrations (not implemented in MVP).
- Folder Structure: Set up the specified project structure with `/components`, `/lib`, `/pages/api`, `/types`, `/styles`, and `/public` folders.
- Tailwind Config: Create `tailwind.config.js` configured for 'Inter' font family and custom colors.
- Environment Template: Create `.env.local.example` template for environment variables.
- Next.js Config: Optimize `next.config.js` for Netlify deployment. Capture environment configurations correctly

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) for a professional and reliable feel, evoking trust and stability.
- Background color: Very light desaturated Indigo (#F0F1F9), providing a subtle contrast that is easy on the eyes.
- Accent color: Blue-Violet (#7986CB) for interactive elements, creating visual interest and indicating functionality.
- Body and headline font: 'Inter' sans-serif for clear and modern readability.
- Use consistently styled icons from `@heroicons/react` to provide clear visual cues.
- Employ a clean, grid-based layout to ensure readability and a professional aesthetic.
- Incorporate subtle transition animations for a polished user experience.
